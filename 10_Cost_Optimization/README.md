# Cost Optimization on AWS

Thư mục này tập trung vào các chiến lược tối ưu hóa chi phí AWS, bao gồm:

- **Amazon EBS Cost Optimization** — Tối ưu hóa chi phí lưu trữ block thông qua lựa chọn volume, chính sách snapshot và quản lý vòng đời.
- **Amazon S3 Cost Optimization** — Cách sử dụng storage class, lifecycle policy và tagging để giảm chi phí lưu trữ đối tượng.
- **Amazon EBS Performance Optimization** — Tối ưu hiệu năng EBS đồng thời kiểm soát chi phí bằng cách chọn loại volume phù hợp và cấu hình IOPS/throughput.
