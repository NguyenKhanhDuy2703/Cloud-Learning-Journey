## StudyBuddy AI Overview 
StudyBuddy AI is an application to help students understand the intricacy of Generative AI. This application gives students access to customize parameters (system prompt, temperature, top P) and allows the integration of Retrieval Augmented Generation resources such as text document uploads, web crawling, and connecting Bedrock Knowledge Bases. StudyBuddy AI uses Nova Pro Model. 

## Command to run StudyBuddy AI
python3 -m streamlit run study_buddy_complete.py
