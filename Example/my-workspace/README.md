# AI Development for Students

> **AWS Event Only:** This workshop is intended to be run at an AWS-hosted event with provided AWS accounts and resources. Running this workshop independently may incur AWS costs. Configured for **us-east-1** or **us-east-2** regions.

A hands-on workshop guiding students from generative AI fundamentals to building advanced agent-based applications using Amazon Bedrock and AWS-native tools.

**Duration:** ~3 hours (3 standalone labs, ~1 hour each)

**Prerequisites:**
- Basic programming knowledge (Python preferred)
- High-level understanding of APIs and cloud services
- No prior AI/ML experience required

## Labs

### Lab 1: Bedrock Fundamentals, Prompting, and RAG
Learn the basics of Amazon Bedrock, prompt engineering, and Retrieval-Augmented Generation by building an AI-powered study guide.

### Lab 2: MCP, Kiro CLI, and Strands Agents
Build agent-based AI systems using the Model Context Protocol and Strands framework to create an AI tutor that generates quiz questions.

### Lab 3: Spec-Driven Development with Kiro
Apply spec-driven development to build an AI interview coach that helps users practice behavioral interviews using the STAR method.
